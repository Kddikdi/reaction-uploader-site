反応集アップローダー / Reaction Uploader

PCで作成した漫画の反応集動画を、開発者本人のTikTokアカウントの下書き（受信箱）にアップロードするための個人用ツールです。一般向けのサービスではなく、開発者本人のアカウントだけで使います。

This is a personal tool that uploads manga reaction videos created on the developer's own PC to the developer's own TikTok account as drafts (inbox), using the TikTok Content Posting API. It is not offered to the public and is used only with the developer's own account.

The final post is always completed manually by the account owner in the TikTok app.

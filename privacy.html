プライバシーポリシー / Privacy Policy

1. 取得する情報 / Information we access

TikTokでの認可時に、開発者本人のアカウントのOpen ID・アクセストークン・リフレッシュトークン、および基本的なプロフィール情報（user.info.basic）を受け取ります。

When the account owner authorizes the app, we receive the account's Open ID, access token, refresh token and basic profile information (user.info.basic).

2. 利用目的 / How we use it

受け取った情報は、本人のアカウントへ動画を下書きとしてアップロードするためだけに使います。

This information is used only to upload videos to the owner's own account as drafts.

3. 保存と共有 / Storage and sharing

トークンは開発者本人のPCにのみ保存し、外部のサーバーへ送信・保存しません。第三者への提供、販売、広告・分析目的の利用は行いません。本サイトはCookieやアクセス解析を使用しません。

Tokens are stored only on the developer's own computer and are never sent to or stored on external servers (other than TikTok's API). We do not share, sell, or use the information for advertising or analytics. This website does not use cookies or tracking.

4. 削除 / Deletion

PC上のトークンのファイルを削除し、TikTokアプリの設定から本アプリの連携を解除することで、いつでも情報を消去できます。

The information can be removed at any time by deleting the token file on the computer and revoking the app's access in TikTok's settings.

5. お問い合わせ / Contact

このサイトのGitHubリポジトリのIssuesからご連絡ください。

Please contact us via the Issues page of this site's GitHub repository.
